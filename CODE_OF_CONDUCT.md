# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1. The full text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

In short: be respectful, welcome newcomers, accept constructive feedback, and focus on what is best for the project and its community. Harassment and personal attacks are not tolerated.

## Reporting

Report unacceptable behavior to the maintainer, João Pedro de Sena Santana ([@joaopssx](https://github.com/joaopssx)), through a private channel on GitHub. Reports are handled confidentially.
